                                                                                BOOKSTORE DATA BASE PROJECT
                                                                             ---------------------------------

CREATE DATABASE IF NOT EXISTS bookstore_db;

USE bookstore_db;

-- 1. Authors
CREATE TABLE Authors (
    author_id INT AUTO_INCREMENT PRIMARY KEY,
    author_name VARCHAR(100) NOT NULL,
    bio TEXT
);

-- 2. Genres
CREATE TABLE Genres (
    genre_id INT AUTO_INCREMENT PRIMARY KEY,
    genre_name VARCHAR(50) NOT NULL
);

-- 3. Customers
CREATE TABLE Customers (
    customer_id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100) UNIQUE,
    city VARCHAR(50),
    join_date DATE
);

-- 4. Books
CREATE TABLE Books (
    book_id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(150),
    price DECIMAL(10,2),
    stock_quantity INT,
    author_id INT,
    genre_id INT,
    
    FOREIGN KEY (author_id) REFERENCES Authors(author_id),
    FOREIGN KEY (genre_id) REFERENCES Genres(genre_id)
);

-- 5. Orders
CREATE TABLE Orders (
    order_id INT AUTO_INCREMENT PRIMARY KEY,
    order_date DATE,
    customer_id INT,
    
    FOREIGN KEY (customer_id) REFERENCES Customers(customer_id)
);

-- 6. Order_Details
CREATE TABLE Order_Details (
    detail_id INT AUTO_INCREMENT PRIMARY KEY,
    order_id INT,
    book_id INT,
    quantity_ordered INT,
    price_at_time_of_order DECIMAL(10,2),
    
    FOREIGN KEY (order_id) REFERENCES Orders(order_id),
    FOREIGN KEY (book_id) REFERENCES Books(book_id)
);

1. Display all books that cost more than 300

query
-----
SELECT * 
FROM Books
WHERE price > 300;

Explanation
------------
SELECT*: SELECT is used to choose data from a table. * means show all columns, so Show every column from the table.
FROM Books : FROM tells SQL from which table the data should come. Books is the table name, so Take the data from the Books table.
WHERE price > 300 : WHERE is used to filter rows. price > 300 means only choose books whose price is greater than 300, so Show only books that cost more than 300.

Medium Questions

1. Find total number of books available in each genre

query
------
SELECT genre_id, SUM(stock_quantity) AS total_stock
FROM Books
GROUP BY genre_id;

Explanation
------------
SELECT genre_id : Show the genre id column
SUM(stock_quantity) : SUM() adds values together. Here it adds stock quantities.
Example:
Fiction books stock:
50 + 20 + 100 = 170
Step 3: AS total_stock
AS gives a new name to the column.
Here the result column is named total_stock.
FROM Books : Use data from Books table.
GROUP BY genre_id : Group rows based on genre_id. SQL calculates total stock separately for each genre.

Output
-------
+----------+-------------+
| genre_id | total_stock |
+----------+-------------+
|        1 |         170 |
|        2 |          60 |
|        4 |          40 |
+----------+-------------+

2. Display average price of books written by each author

query
------
SELECT author_id, AVG(price) AS average_price
FROM Books
GROUP BY author_id;

Explanation
------------
SELECT author_id : Show author ids.
AVG(price) : AVG() calculates average. SQL adds all prices and divides by total books.
Example:
For Chetan Bhagat:
(250 + 300) / 2 = 275
AS average_price : Rename the result column.
GROUP BY author_id : Create groups for each author.

|         1 |    275.000000 |
|         2 |    450.000000 |

query
-----

COUNT(order_id) : COUNT() counts rows. Counts how many orders each customer placed.
GROUP BY customer_id : Group orders by customer.
HAVING COUNT(order_id) > 1 : HAVING filters grouped data. Show only customers whose order count is greater than 1.
